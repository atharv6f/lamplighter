`wordcount.py FILE` prints the number of words in a file, as
`words: 12`. Add a `--lines` flag. With it, the program prints one more
line after that one: `lines: N`, where N is the number of lines in the
file. A last line without a newline at its end counts as a line, and an
empty file has 0 lines. Without the flag, the output stays as it is.
